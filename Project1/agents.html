Agents

Agents are the characters you can play. Each one has special abilities. The four main roles are:

  • Duelist: helps lead attacks. Example: Jett.
  • Initiator: helps the team find opponents. Example: Sova.
  • Controller: blocks sightlines. Example: Brimstone.
  • Sentinel: helps protect an area. Example: Sage.
